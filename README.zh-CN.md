# Aide

[English](README.md) | 简体中文

Aide 是自托管的个人 Agent，持续理解你关注的人和事，并跟进你交办的工作。通过网页或 Lark，你可以随口提问、交办目标，或安排一项持续职责。Aide 将不断到来的消息和外部变化组织成主题，积累认识，在已有委托范围内推进工作，需要你决定时再询问，让你少重复背景、少催进度，把注意力留给重要判断。

例如：“跟进这个 PR 直到合入，处理评审意见，需要我决策时再问我，合入后告诉我。”同一项工作可以跨越多轮执行和等待。关闭聊天窗口或关掉笔记本后，Aide 仍会在服务器上继续工作。

## 可以让它做什么

- **回答问题或直接办事。** “读取当前项目的 README，告诉我如何启动。”Aide 可以读取文件，使用运行环境中已有的 CLI。
- **持续跟进一个目标。** “跟进这个 PR 直到合入。”Aide 将目标、进展和等待条件保留在同一事项中，你可以随时补充信息或作出决定。
- **承担一项持续职责。** “每天早上检查项目待办，有新阻塞时告诉我。”每轮可以经历调查、执行和等待，完成后再等下一轮。
- **关注外部变化。** Aide 可以观察需求平台中指定负责人名下的需求与评论，并在工作项中答复；也可以关注已配置 Kubernetes 工作负载的变化，查询 GitHub / GitLab 的 PR 状态与评论。配置方式和当前覆盖范围见[连接与观察](docs/connector/README.md)。

Aide 会把新信息关联到相关话题和已有工作，在已有委托范围内继续推进；发现新机会时，可以向你建议下一步。没有值得报告的新情况时保持安静。

## 话题、事项与安排

**话题（Topic）**组织相关的信息、认识和工作。Aide 将同一件事的多次变化整合为持续更新的笔记（Note），提炼对主题和人物的长期认识，并随理解加深调整话题层次。这些认识帮助它理解后续消息、接上已有进展。

Aide 的助手 **Chief** 直接回答日常问题，并通过事项和安排帮你持续跟进工作。

- **事项（Task）**有明确的完成条件，例如让一个 PR 合入。它可以持续几分钟或几周，经历多轮执行和等待。
- **安排（Routine）**承担持续职责，例如每天早上检查项目阻塞。完成一轮后，会继续等待下一轮。

创建事项表示 Aide 已接下目标。你可以离开话题，稍后回来查看进展和结果。也可以在同一话题中补充信息、回答问题，或要求暂停。

每个话题还可以开启定时回顾，默认关闭。在网页中开启后，Chief 会重新查看这个话题的进展和可采取的下一步，默认每小时一次。关闭回顾只停止这些检查；已有事项、安排和外部观察仍按各自的节奏继续。

## 快速开始

需要 Node.js 22.19 或更高版本安装依赖。运行服务所需的 Bun 已包含在依赖中。

```sh
git clone https://github.com/compforge/aide.git
cd aide
npm ci
```

在 `~/.aide/config.yaml` 中配置 Chief 与 Task / Routine Agent 的模型访问。如果你已经使用 Pi，Aide 可以沿用 `~/.pi/agent` 中的模型设置与认证。[配置指南](docs/configuration.md)说明了模型服务、凭证、技能和外部系统连接的配置方式。修改配置后需要重启 Aide。

选择 Aide 的工作目录并启动：

```sh
AIDE_CWD=/path/to/work AIDE_TIMEZONE=Asia/Shanghai npm start
```

打开 <http://127.0.0.1:7433>，试着输入：“读取工作目录中的 README，告诉我如何启动项目。”请确保服务能够访问请求涉及的文件、CLI 和凭证。

网页左侧选择话题，中间查看消息与执行进展，右侧查看话题摘要、近期记录、事项和安排。刷新后可查看服务当前保留的近期执行详情。

Linux 常驻运行、代理配置和 SSH 转发见[部署与诊断](docs/deployment.md)。

## 接入 Lark

在 Web「接入」页面添加并启用 Lark 渠道，重启 Aide 后即可通过机器人单聊或群内 @机器人交办工作，无需公网回调地址。机器人创建与权限见[Lark 接入](docs/channel/lark.md)，主动联系你的配置见[配置指南](docs/configuration.md#沟通渠道)。

当前支持单聊和群内 @本机器人的文字消息；Agent 的权限请求仍需在网页中处理。

## 使用前了解

Aide 当前面向单用户，由一个服务实例运行。HTTP 入口没有认证，请通过可信的本地连接或 SSH 隧道访问。话题用于组织消息与相关工作，不提供账号或权限隔离，长期记忆也可能跨话题共享。

状态默认保存在 `~/.aide`。服务需要保持运行才能推进工作。重启后，Aide 恢复已保存的工作和调度；执行中断或结果无法校验时，会等待你核对后明确继续。重试前请核对外部操作是否已经生效，暂停或删除工作不能撤销已发生的动作。

Aide 使用的模型可能判断错误。重要结果请结合实际文件、产物或外部系统核对。
